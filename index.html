Google Play / App Store 商店素材违规内容清单

适用对象：DramaBox 等出海短剧 App · 覆盖图标、截图、Feature Graphic / 预览视频封面、宣传图
更新：2026-10-24 依据：Google Play Metadata Policy / Store Listing Best Practices / 不当内容政策 依据：Apple App Review Guidelines 1.1、1.4、2.3、5.2

0. 三条基本规则

  • 判定基准不同。Google 卡「内容合规」（素材须适合普通受众）；Apple 卡「真实性 + 4+ 分级」——2.3.8 规定即便 App 是 17+，图标、截图、预览仍须保持 4+。
  • 商店素材 ≠ 剧内素材。两套分级标准，必须物理隔离。
  • 后果不对等。Google 逐级升级至账号封禁；Apple 2.3.1(b) 对误导性营销可直接终止开发者资格。

2. Google Play：违规图片清单

素材必须适合普通受众（general audience）。

违规类别具体表现 / 判定标准风险
性暗示 / 性化描绘 胸部、臀部、生殖器或其他被性化部位——真人与插画一视同仁；性挑逗姿势；衣着极度暴露。擦边即算，不要求露点。 高危
图形暴力 / 毒品 图标、宣传图、视频中突出描绘暴力或暴力威胁；描绘违禁药物使用。EDSA 豁免在商店素材中不成立。 高危
排名 / 成绩暗示 #1 Best Top Popular 年度应用、New、获奖图标、编辑推荐字样。 高危
价格 / 促销 / CTA X% off 返现 限时免费 立即下载。 高危
冒充 / 误导关联 图标与既有产品高度相似；用企业 logo 暗示官方身份；无新消息却加未读红点、加下载箭头。 高危
素材与实机不符 截图非真实 App 界面；展示 App 不具备的功能；旧版本 UI 未同步。 高危
版权 / 格式字符 未授权素材；标题图标中出现 emoji、颜文字、重复特殊符号（★ ☆ ！！）、非品牌全大写。 中危
硬性规格：图标 512×512 32-bit PNG 带 alpha ≤1024KB；Feature Graphic 1024×500 JPEG/24-bit PNG 无 alpha；截图 ≥2 张、单边 320–3840px、长边 ≤ 短边 2 倍；含文字的截图需按语种分别出图。

3. App Store：违规图片清单

核心是「准确元数据」+「4+ 分级铁律」。

条款规则对图片素材的要求风险
2.3.8 元数据须保持 4+ 短剧头号杀手。即便 App 17+，图标、截图、预览仍须适合所有受众——掐脖、掌掴、持刀、血迹、吻戏特写一律不可用。 高危
2.3.3 截图须展示使用中 不能只是标题封面、登录页、启动页；底层必须是真实界面，允许文字叠加。经验值：整套图 ≥60% 含可见 UI。 高危
2.3.7 禁价格与无关词 名称、副标题、截图、预览不得含价格、商标术语、热门 App 名或无法证实的产品声明。 高危
2.3.2 内购须明示 截图/预览须标明哪些剧集、订阅需额外付费。 高危
2.3.10 禁其他平台 元数据不得出现其他移动平台或替代应用市场的名称、图标、图像（安卓机模、Google Play 图标均禁止）。 高危
2.3.9 授权与虚构信息 须有权使用全部素材；必须显示虚构账户信息，不得用真实个人数据。 高危
2.3.1 禁误导性营销 宣传 App 不提供的内容或虚假价格 → 下架 + 禁止替代分发 + 开发者账号终止。 高危
1.1 / 1.4 内容安全 1.1.4 公然色情；1.1.2 写实暴力残害；1.1.1/1.1.5 歧视与宗教；1.4.3/1.4.5 赌博、烟草、违禁药物。 中危
硬性规格：iPhone 6.9" 1260×2736（另接受 1290×2796、1320×2868）；iPad 13" 2064×2752；不接受透明通道与动图；预览视频只能用 App 自身屏幕录制画面（2.3.4）。
政策依据：Google Play Developer Program Policy（Metadata / 不当内容 / Store listing best practices）、Apple App Review Guidelines（1.1、1.4、2.3、5.2）。
政策会动态调整，重大素材改动前建议回查官方原文；本清单为内部执行标准，最终审核结论以平台为准。
