出海短剧 App（DramaBox 等）商店素材的合规红线清单，覆盖图标、截图、Feature Graphic、预览视频封面与宣传图。

## 核心结论

1. Google 卡「内容合规」——素材必须适合普通受众。
2. Apple 卡「真实性 + 4+ 分级」——即便 App 分级 17+，图标、截图、预览仍须保持 4+。
3. 短剧 App 素材拒审集中在：性暗示姿势与暴露、暴力血腥、虚假宣传、非本平台元素、素材与线上版本不符。

## 政策依据

- Google Play Developer Program Policy：Metadata、Store listing best practices、不当内容
- Apple App Review Guidelines：1.1、1.4、2.3、5.2

政策动态调整，重大素材改动前请回查官方原文；本清单为内部执行标准，最终审核结论以平台为准。
